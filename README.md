# GHOST MACHINES: A Tour of NASA's Left-Behind Explorers

An interactive, story-driven educational website. Visitors play space archaeologists exploring the abandoned NASA robotic hardware on the Moon and Mars. There are eight artifacts, each with a map marker, a dossier and a fictional first-person "Last Transmission" that can be read aloud.

> **Unofficial educational project.** Not affiliated with, sponsored by, or endorsed by NASA. No NASA logos or insignia are used.
> **AI disclosure:** the code and written content in this repository were **generated by an AI assistant (Claude, Anthropic)** from the team's prompts. See [AI-assisted development disclosure](#ai-assisted-development-disclosure).

## Quick start

Native ES modules need a local web server (opening `index.html` directly will not work).

```
python3 -m http.server 8000      # then open http://localhost:8000
```

Or use VS Code's Live Server on `index.html`. Open the `ghost-machines` folder itself, so that `css/` and `js/` sit beside `index.html`.

## What it does

- Cinematic landing screen with a launch transition.
- Moon and Mars exploration console: stylized maps, eight glowing artifact markers, a selected-artifact panel and a historical timeline.
- A dossier for each artifact, all rendered by one reusable component, with confirmed facts distinguished from scientists' interpretations and NASA source links.
- Last Transmission: fictional narrations read aloud with the browser's built-in speech synthesis, with a waveform and transcript.
- A 14-milestone timeline (1966 onward) linked to the map and dossiers.
- **THE LOST MISSION:** a visual novel with eight chapters, one per machine. Play a newly recruited Junior Space Archaeologist: inspect clickable parts of each scene, make decisions, collect evidence, solve short science challenges, and read a labeled "real history" card with NASA source links. The characters and the Deep Archive Survey are **fictional and labeled as fiction**; the machines and science are real. **Voice:** story lines are read aloud with the browser's built-in voices, with a different voice and delivery for each character (Director Vale, ARCHIE the robot assistant, and the recruit). There is a Voice On/Off switch (saved), a Replay voice button, and Read aloud buttons for the hotspot notes and history cards. The story works silently if the browser has no speech support. Chapters unlock in order, can be replayed, and never lock the map or dossiers. Progress is saved in the same `localStorage` store as everything else.
- **Junior Space Archaeologist challenge:** 10 multiple-choice questions (four options each, shuffled every attempt), instant feedback with a short explanation, a score tracker, a results screen and unlimited retakes. Your best score is kept.
- **Achievement:** score 70% or more to earn the JUNIOR SPACE ARCHAEOLOGIST badge (illustration, score and completion date). Add an optional name and download a PNG certificate, made in your browser with the Canvas API. No account or backend.
- **Expedition log:** artifacts discovered and cataloged, transmissions heard, timeline milestones explored and quiz attempts. Click the progress meter in the top bar.
- All progress is stored in one place (`localStorage`) on the visitor's device. The quiz unlocks at 8/8 artifacts cataloged.

## Developer notes

**Tests** (Node, no packages): `node tests/boot-test.mjs` loads the real page and checks every module is wired in; `node tests/quiz-flow.mjs` plays the quiz end to end and checks scoring, the badge and storage; `node tests/story-voice.mjs` checks the visual novel's voices (per-character voices, toggle, replay, blocked-voice handling, stopping on leave); `node tests/story-flow.mjs` plays all eight visual novel chapters through their real buttons and checks decisions, hotspots, evidence, challenges, unlocking, replay, resume and the typewriter. These tests use a small DOM stand-in, so they cannot judge how the page *looks*: always check the layout and artwork in a real browser.

**Progress rules** (`js/core/store.js` is the only place these live). Status is derived, never stored: undiscovered, opened, cataloged. An artifact is cataloged when its dossier was opened, read to the end, and its Last Transmission was heard (or the transcript marked as read). Spirit and Opportunity also need both sites viewed. The quiz unlocks at 8/8. The badge is awarded at 70% or more, with the best score kept. Other counters (artifacts discovered, transmissions heard, milestones explored, quiz attempts) are derived from the same stored state, so they cannot disagree.

**Console helpers** (on localhost only):
```
ghost.store.getSteps('surveyor-3')
ghost.store.discoveredCount     // also: transmissionCount, milestoneCount, quizAttempts, bestQuiz
ghost.store.recordStep('surveyor-3', 'opened')
ghost.store.reset()
```

**Timeline.** Milestones live in `js/data/timeline.js`. To use a NASA photo instead of an illustrated plate, add `photo: { src, alt, credit }` to an event. **Before adding any image, follow the checklist in `ATTRIBUTION.md` §7.**

**Maintaining the register.** Add a row to `ATTRIBUTION.md` in the same commit as any new library, snippet, image, font, icon, audio file or data source.
